## 四、数据服务能力边界

### 4.1 当前可提供（local 模式）

1. **产品检索**：按型号名称、系列、操作系统、配置范围检索
2. **配置筛选**：按内存、存储、屏幕类型筛选配置
3. **事实提取**：提取产品事实的结构化段落，标注变体适用范围
4. **图片索引**：提供图片文件路径、画面说明、原图URL
5. **适用性判断**（基于现有证据）：
   - `supported`：产品事实或P7官方支持条目中明确支持
   - `unsupported`：产品事实或卖点限制中明确不支持（如"仅Windows版支持"）
   - `unknown`：知识库中未提及
   - `needs_verification`：知识库提及但标注"需核验"或"以实际为准"
6. **覆盖范围报告**：明确哪些资料已有、哪些缺失

### 4.2 不提供（避免虚构）

1. **未经证实的兼容性**：第三方软件、智能家居设备、扩展坞，**不能**根据品牌名或常识推断
2. **性能实测数字**：续航小时、传输速度、充电时长、启动时间，**不能**虚构
3. **价格承诺**：P4机密不直接暴露；P1/08价格快照需标注"核验时间"和"以商城当前为准"
4. **企业政策**：VPN、策略管理、教育优惠，**需单独核验**

### 4.3 ima 模式（接口适配，标注"未验证"）

- 实现 ima API 调用逻辑，但 `getStatus` 明确标注 `state: "not_verified"`
- 返回结果带 `origin: "ima"` 和 `verificationNote: "ima接口未经真实凭证验证"`

## 五、建议的使用流程

1. **产品选型阶段**：用 `searchProducts` 获取候选列表，用配置筛选缩小范围
2. **事实核验阶段**：用 `getProductDetails` 获取产品事实，**保留变体标记和脚注**
3. **场景适用性判断**：
   - PC基础能力（屏幕、性能、接口）：直接引用产品事实
   - 多设备协同（超级终端、华为分享）：引用产品事实+P7官方支持条目，**标注条件**（账号、版本、对端设备）
   - 智能家居、第三方软件、扩展坞兼容：返回 `unknown`，不推断
4. **图文生成阶段**：
   - 图片用 `readImage` 读取本地文件或 ima media
   - 价格引用 P1/08 快照，**标注核验时间**和"以商城当前为准"
   - 性能数字只用规格参数（Wh、GHz、GB），**不虚构**续航小时或传输速度
5. **合规检查**：
   - P4 内容不直接暴露
   - mock 标记必须保留
   - 变体限定（"仅Windows版"）必须保留
